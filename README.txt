==================================================
保險業務員考照 APP - 使用說明
==================================================

【專案內容】
- 469 道精選題庫（從必勝寶典提取）
- 12 章節分類（保險實務7章 + 保險法規5章）
- 完全離線運作，無需網路

【APP 功能】
✓ 首頁總覽（題數、錯題本、收藏統計）
✓ 章節題庫（依章節練習，顯示進度）
✓ 題庫練習（選答、即時對錯、收藏題目）
✓ 模擬考試（50題 / 100題隨機抽題）
✓ 考試結果（分數、答題明細）
✓ 錯題本（記錄錯誤題目，可複習）
✓ 收藏題目（書籤功能）
✓ 學習進度（各章節正確率統計）

==================================================
【安裝步驟】
==================================================

需要安裝：
1. Flutter SDK  →  https://flutter.dev/docs/get-started/install/windows
2. Android Studio（含 Android SDK）
3. Java 17

安裝完成後：

1. 開啟命令提示字元，進入此資料夾：
   cd "C:\Users\sthou\OneDrive\文件\Claude\Projects\Exam Master App\insurance_exam_app"

2. 執行一鍵建置腳本：
   setup_and_build.bat

3. APK 輸出位置：
   build\app\outputs\flutter-apk\app-release.apk

==================================================
【手動安裝到手機】
==================================================

方式 A（USB 傳輸）：
  將 app-release.apk 複製到手機，開啟檔案管理員安裝。
  需在「設定 > 安全性」啟用「允許未知來源」。

方式 B（ADB）：
  adb install build\app\outputs\flutter-apk\app-release.apk

==================================================
【開發測試】
==================================================

接上手機後執行：
  flutter run

即時熱重載（按 r）、重新啟動（按 R）
